# SharePoint Solutions

Scripts and patterns for SharePoint Online using **PnP PowerShell**.
No tenant names or credentials committed — configure via `.env`.

- `scripts/New-AssetList.ps1` — provision an Asset Manager list
- `scripts/Import-AssetsFromCsv.ps1` — bulk import assets from CSV

```powershell
Install-Module PnP.PowerShell -Scope CurrentUser
```
