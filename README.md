## 👋 About Me

I'm an **IT Support Specialist** who works at the intersection of **help‑desk operations** and **automation engineering**. Day to day I keep users productive — but my real passion is spotting the repetitive, manual tasks behind the scenes and replacing them with clean, dependable automation.

Over time this has grown into a toolkit of **PowerShell** and **Python** scripts, **Power Platform** solutions (Power Automate, Power Apps, Power BI), and **SharePoint** integrations that streamline onboarding, asset management, monitoring, and approvals. I'm currently expanding into **Microsoft Fabric** and modern data analytics.

> This portfolio is a curated, **fully genericized** showcase of that work — no client, employer, or personal data is included. Every script uses placeholder values and is safe to read, run, and reuse.

## 🚀 How to Explore

1. **Browse a project** — click any link in the table above; each folder has its own README.
2. **Run something** — most scripts are parameterised and ready to run. Example:
   ```powershell
   .\it-automation-toolkit\powershell\Get-ADUserReport.ps1 -OutputPath .\users.csv

   ```

## 🔒 Data & Safety

Everything here is deliberately **safe to publish**:

- ✅ **No credentials** — configuration is done via `.env` files (see each `.env.example`); real secrets are `.gitignore`‑blocked.
- ✅ **No real data** — all names, domains, servers, and IPs are placeholders (`example.local`, `SERVER01`, `192.0.2.x`).
- ✅ **No client or employer information** — projects are genericized versions inspired by real work.
