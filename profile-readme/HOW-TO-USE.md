# How to use this Profile README

GitHub shows a special README at the top of your profile if you create a repository whose **name is exactly your username**.

## Steps

1. Copy your GitHub username (example: `mateuszdubak`).
2. Create a **new public repo** named exactly the same: `mateuszdubak/mateuszdubak`.
3. Tick **"Add a README file"**.
4. Replace its content with the `README.md` from this folder.
5. Replace `YOUR_USERNAME` in the stats badge with your real username.
6. Commit. Your profile page now shows the README automatically.
